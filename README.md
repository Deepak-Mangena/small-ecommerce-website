# 🛒 Small E-Commerce Website

A responsive e-commerce website built from scratch using HTML5 and CSS3.

## 📌 About the Project

This project is a front-end e-commerce website created to practice and strengthen my HTML and CSS skills.

The website focuses on creating a clean, responsive layout that adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive design
- Navigation bar
- Product sections
- Product cards
- Categories/sections
- Clean and user-friendly interface

## 📱 Responsive Design

The website is designed to work across different screen sizes and devices.

## 🎯 What I Learned

- Structuring webpages using semantic HTML
- Creating responsive layouts with CSS
- Using Flexbox and CSS positioning
- Styling navigation bars and product cards
- Working with images and different screen sizes
- Organizing a front-end project

## 🚀 How to Run

1. Download or clone this repository.
2. Open `shoppers - Copy.html` in your browser.
3. Make sure the required images are available in their expected location.
